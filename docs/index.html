Kenmerken

Alles wat je van een persoonlijke assistent verwacht

🎙️

Spraakinvoer

Klik op de microfoon en spreek — de Web Speech API transcribeert je woorden in realtime en stuurt ze automatisch naar Dutchy.

🔊

Spraakuitvoer

Dutchy leest elk antwoord hardop voor in het Nederlands. Zet het met één klik uit als je stilte wilt.

⚡

Streaming antwoorden

Tekst verschijnt in realtime terwijl Claude het genereert — geen wachten tot het volledige antwoord klaar is.

🧠

Adaptief redeneren

Aangedreven door Claude Opus met adaptief denken — Dutchy denkt automatisch dieper na bij moeilijke vragen.

🇳🇱

Nederlandse persoonlijkheid

Direct, warm en no-nonsense. Spreekt altijd Nederlands. Behandelt je als een maatje, niet als een eindgebruiker.

🖥️

Zelf gehost

Draait op een Raspberry Pi, thin client of een oude laptop. Geen cloud, geen abonnement — alleen je eigen API-sleutel.

📦

Geen externe afhankelijkheden

Volledig zelfstandige frontend — werkt ook offline (behalve de API-aanroep). Geen bibliotheken van het internet nodig.

💬

Volledig sessiegeheugen

Dutchy onthoudt alles wat er in een sessie is gezegd. De context blijft bewaard — je hoeft jezelf nooit te herhalen.

Aan de slag

Draait in drie stappen

Je hebt alleen Python 3.10+ en een Anthropic API-sleutel nodig.

1

Klonen en installeren

Kloon de repository en installeer de drie Python-afhankelijkheden.

# Klonen
git clone https://github.com/rein033/dutch-ai.git
cd dutch-ai

# Installeren
pip install -r requirements.txt
2

API-sleutel instellen

Kopieer het voorbeeldbestand en plak je sleutel van console.anthropic.com.

cp .env.example .env
# Pas .env aan:
ANTHROPIC_API_KEY=sk-ant-…
3

Dutchy starten

Start de Flask-server en open http://localhost:5000 in je browser. Vanuit andere apparaten gebruik je het lokale IP-adres van je machine.

python server.py

# Op de achtergrond draaien:
nohup python server.py > dutchy.log &
