Features

Everything you'd want from a personal assistant

🎙️

Voice input

Click the mic and speak — Web Speech API transcribes your words in real time and sends them to Dutchy automatically.

🔊

Voice output

Dutchy reads every response aloud via SpeechSynthesis. Toggle it off with one click when you're in a quiet place.

⚡

Streaming responses

Text appears in real time as Claude generates it — no waiting for the full response to load.

🧠

Adaptive thinking

Powered by Claude Opus with adaptive reasoning — Dutchy thinks harder on hard questions automatically.

🇳🇱

Dutch personality

Direct, warm, no-nonsense. Dutch phrases sprinkled in. Treats you like a maatje, not a user.

🖥️

Self-hosted

Runs on a Raspberry Pi, thin client, or any old laptop on your LAN. No cloud, no subscription — just your API key.

📦

Zero CDN dependencies

Fully self-contained frontend — works offline (except for the API call). No fonts, no libraries loaded from the internet.

💬

Full session memory

Dutchy remembers everything said in a session. Context carries forward — no need to repeat yourself.

Get started

Running in three steps

Python 3.10+ and an Anthropic API key are all you need.

1

Clone and install

Clone the repo and install the three Python dependencies.

# Clone
git clone https://github.com/rein033/dutch-ai.git
cd dutch-ai

# Install
pip install -r requirements.txt
2

Add your API key

Copy the example env file and paste in your key from console.anthropic.com.

cp .env.example .env
# Then edit .env:
ANTHROPIC_API_KEY=sk-ant-…
3

Start Dutchy

Run the Flask server. Open http://localhost:5000 in your browser — or use your machine's local IP from any device on the network.

python server.py

# To run in the background:
nohup python server.py > dutchy.log &
